# Area Expert

> Contenuti disponibili dal livello Expert. Qui vedi cosa contiene l'area.

- 🔒 [PURO core](core/puro-core/) — Il motore minimo, legato alla matricola IBM i, che fa girare le applicazioni PRODIGYT.
- 🔒 [QIQ, motore di query](core/qiq/) — Motore di query su DB2 con filtri, ordinamenti, selezione campi e composizione SQL. Alimenta i viewer.
- 🔒 [Anagrafica clienti, demo CRUD](demo/demo-anagrafica-clienti/) — Programma RPG completo di gestione clienti: lista con filtri, dettaglio su due pagine, inserimento, modifica, ricerca F4.
- 🔒 [Lista ordini con dettaglio righe](demo/demo-lista-ordini/) — Interrogazione ordini con filtri dinamici, testata e drill-down sulle righe, in SQL embedded.
- 🔒 [Ricalcolo giacenze, demo batch](demo/demo-ricalcolo-giacenze/) — Programma batch di ricalcolo giacenze di magazzino dai movimenti.
- 🔒 [KB e skill per gli assistenti IA](kb/kb-assistenti-ia/) — La conoscenza di PURO pronta per gli assistenti di sviluppo: Claude e, dopo lo studio, IBM Bob.
- 🔒 [Osservare un job IBM i dall'esterno](kb/osservare-job-ibmi/) — Come leggere memoria e stato di un job in esecuzione, con e senza debug.
- 🔒 [Convertitore RPG fisso → free](migrate/convertitore-fisso-free/) — Converte i sorgenti RPG a posizioni fisse in formato free.
- 🔒 [Istruzioni IA per creare una skin](skin/istruzioni-ia-skin/) — Prompt e istruzioni per farsi generare una skin PURO da un assistente AI.
- 🔒 [Connettore IA per IBM i](tools/connettore-ia-ibmi/) — Server MCP che dà a un assistente AI gli strumenti per leggere sorgenti, elencare oggetti ed eseguire comandi su uno o più IBM i via SSH.
- 🔒 [DDS Workbench](tools/dds-workbench/) — Pagina web standalone che legge un sorgente DDS e ne mostra struttura, campi, costanti e keyword, con vista 5250 e vista moderna affiancate.
- 🔒 [Plugin VS Code](tools/plugin-vscode/) — Pezzi di PURO dall'editor, per esempio la compilazione.
- 🔒 [PURO WRKINS](utility/puro-wrkins/) — Tool aggiuntivo per PURO, già esistente sui nostri sistemi.
- 🔒 [Agenda e calendario](viewer/agenda-calendario/) — Liste drag & drop tipo agenda e calendario attività.
- 🔒 [Container e catalogo prodotti](viewer/container-catalogo/) — Viewer per container e catalogo visuale prodotti.
- 🔒 [Framework viewer](viewer/framework-viewer/) — Come è fatto un viewer: modulo JS+HTML+CSS con input e output JSON, collegato a un subfile o a un server Node.js. La base per crearne di propri.
- 🔒 [Grafici evoluti](viewer/grafici-evoluti/) — Grafici a bolle e a gravità, dove peso, dimensione, colore e forma rappresentano valori.
- 🔒 [Mappa del magazzino](viewer/mappa-magazzino/) — Planimetria trasformata in mappa interattiva, con corridoi e scaffali configurabili e vista in alzato.
- 🔒 [Matrice configurabile e schedulatore](viewer/matrice-schedulatore/) — Pianificatore a matrice: l'utente sceglie i campi e li dispone con drag & drop, un batch aggiorna i file.
- 🔒 [Statistica a 5 dimensioni](viewer/statistica-5-dimensioni/) — Visualizzazione statistica multidimensionale adattabile ai file dell'utente.
- 🔒 [Viewer di sistema IBM i](viewer/viewer-di-sistema/) — Query Explorer, Job Monitor, Spool Viewer, attività utenti, Object Browser, code messaggi.
- 🔒 [Viewer file IFS](viewer/viewer-file-ifs/) — Visualizza testo, documenti, sorgenti RPG colorati, HTML.
