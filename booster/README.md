# Area Booster

> Contenuti disponibili dal livello Booster. Qui vedi cosa contiene l'area.

- 🔒 [WHATS-I per AS400](app/whats-i/) — Messaggistica interna per IBM i in stile chat, con backend RPG e front end PURO. Permette di rispondere ai messaggi bloccanti (MSGW) dallo smartphone.
- 🔒 [Convenzioni per programmi demo](demo/convenzioni-programmi-demo/) — Le regole di scrittura dei programmi demo: naming, layout pannelli, navigazione, attributi, subfile, finestre di ricerca.
- 🔒 [Database aziendale demo](demo/database-demo/) — Database italiano di prova con 29 tabelle (anagrafiche, ordini, DDT, fatture, magazzino) e generatore Python con 5 profili di settore. Si carica su IBM i con DDS o DDL già pronti.
- 🔒 [Knowledge base in formato IA, base](kb/kb-ia-base/) — La conoscenza di base su PURO e la modernizzazione, strutturata perché un assistente AI possa usarla direttamente.
- 🔒 [Altri strumenti per la modernizzazione](modernizzazione/altri-strumenti-modernizzazione/) — Il filone resta aperto: gli strumentini che servono a gestire una modernizzazione, anche su richiesta degli iscritti.
- 🔒 [Analizzatore di applicazioni RPG](modernizzazione/analizzatore-applicazioni/) — Mappa le relazioni tra programmi e database di un'applicazione.
- 🔒 [Analizzatore di librerie](modernizzazione/analizzatore-librerie/) — Che cosa c'è in una libreria: oggetti, sorgenti, riferimenti, cosa si usa ancora.
- 🔒 [Dalle DDS a SQL](modernizzazione/dds-sql/) — Trasforma le definizioni DDS dei file fisici e logici in istruzioni SQL.
- 🔒 [Modifiche globali ai sorgenti](modernizzazione/modifiche-globali-sorgenti/) — Cerca e sostituisci su tutti i membri sorgente, con anteprima e annullamento.
- 🔒 [Playground CSS](skin/playground-css/) — Pagine standalone per sperimentare box, testate, tabelle, window e titoli con gli stili reali di PURO, e generare il CSS.
- 🔒 [Skin della community](skin/skin-della-community/) — Raccolta di skin contribuite dai membri, firmate dall'autore.
- 🔒 [Skin pack](skin/skin-pack/) — Skin altamente personalizzabili per PURO, definite a token e applicabili dal Composer.
- 🔒 [Estensioni JavaScript](snippet/estensioni-javascript/) — Piccole estensioni pronte: aggiungere un bottone, aggiungere campi, spostare elementi, intervenire sulla configurazione.
- 🔒 [Leggere JSON in RPG con YAJL](snippet/json-con-yajl/) — Esempi di parsing JSON ad albero in RPG ILE con la libreria YAJL, anche con chiavi non note a priori.
- 🔒 [Keyword PURO nelle DDS](snippet/keyword-puro-dds/) — Esempi pratici della sintassi COMPONENT[...] per trasformare un campo in componente direttamente dal sorgente DDS.
- 🔒 [NORMXML, normalizzatore di encoding](snippet/normxml/) — Service program RPG che riconosce e converte l'encoding dei file XML (es. FatturaPA in ISO-8859-1) prima del parsing con XML-INTO.
- 🔒 [Ricette regole.js](snippet/ricette-regole-js/) — Le trasformazioni più usate con le regole JavaScript: titolo nella barra, messaggi in fondo, pulizia delle opzioni di subfile, pseudo-frame, window responsive, tabelle, grafici, funzioni su campo.
- 🔒 [Come modernizzare la vostra applicazione](tutorial/come-modernizzare/) — Guida operativa: cosa aspettarsi, come preparare l'applicazione, cosa è automatico e cosa si rifinisce a mano.
- 🔒 [Costruire cose nuove su IBM i, base](tutorial/costruire-cose-nuove/) — Web services REST e SOAP da e verso RPG, SQL avanzato e DB2 moderno.
- 🔒 [Interrupt applicativo](utility/interrupt-applicativo/) — Librerie per l'interruzione controllata dei programmi applicativi.
- 🔒 [I/O XML e JSON per RPG](utility/io-xml-json/) — Service program esterno per leggere e scrivere XML, JSON e altri formati dai programmi RPG.
- 🔒 [Drag & drop righe](viewer/drag-drop-righe/) — Mini viewer per riordinare righe trascinandole.
